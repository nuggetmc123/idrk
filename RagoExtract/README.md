# Rago Extract

A VR ragdoll extraction shooter for Unity (Meta Quest + PC VR), in the spirit of Ghost of Tabor and Contractors: Exfil Zone.

Everything (guns, characters, maps, textures, sounds) is generated by code at runtime. There are no imported art files.

## Open it

1. Install **Unity 6** (6000.0 LTS or newer) with **Android Build Support** (+ OpenJDK + Android SDK & NDK) from Unity Hub.
2. Unzip `RagoExtract.zip` first (right-click → **Extract All**). Don't open it from inside the zip.
   Unity Hub → **Add → Add project from disk** → pick the folder that directly contains
   `Assets`, `Packages` and `ProjectSettings`. If Hub says *"not a valid project"*, you picked
   the folder one level too high (or the zip itself).
3. On first open the project sets itself up automatically:
   - configures the Quest player settings, layers and input,
   - creates and opens `Assets/RagoExtract/Scenes/RagoExtract.unity`,
   - opens the **Rago Extract** tab and imports VR (XR Management + OpenXR), multiplayer (Netcode for GameObjects, Lobby, Relay) and voice chat (Vivox), then enables OpenXR + Meta Quest support.

   Unity recompiles a few times during the imports. Leave it open until the tab shows all **OK**.
4. Press **Play**. Without a headset you can play with keyboard + mouse.

## The Rago Extract tab (top menu → Rago Extract)

| Button | What it does |
|---|---|
| Import VR | Installs XR Plug-in Management + OpenXR, then enables the OpenXR loader for Android (Quest) and PC, Meta Quest support and Touch controller profiles |
| Import Multiplayer | Installs Netcode for GameObjects + Lobby + Relay + Vivox voice |
| Configure VR + Project | Re-applies player settings, layers, scene and XR setup |
| Build APK | Switches to Android and builds `Builds/RagoExtract.apk` |
| Build And Run On Quest | Builds and installs on a USB-connected Quest (developer mode on) |
| Build Windows | PC VR / desktop build |

### Online multiplayer (one-time)
Multiplayer needs a free Unity Cloud project:
1. **Edit → Project Settings → Services**: sign in and link or create a project.
2. In the Unity Cloud dashboard, enable **Lobby**, **Relay** and **Vivox** for it.

Without this the game runs offline: solo raids against AI, with the same queue and kiosk.

## How the game works

- **Bunker** is your private base. It has your stash wall (gun rack and shelves, saved automatically), a raid kiosk, a shooting range with steel targets, a settings board and a lift to the Market.
- **Market** is a shared safe zone where players meet, with proximity voice chat. It has 4 NPC traders:
  - **Viktor** (rifles and shotguns)
  - **Mara** (sidearms, SMGs, holo sights, ammo)
  - **Doc Hale** (meds)
  - **Silas** the Fence (buys anything, sells vault keycards)

  Buy with the BUY buttons; your item appears on the PICKUP tray. Put items on the SELL tray to sell them.
- **Kiosk**: pick a map and queue. Each raid holds 4-10 players. The queue tries to reach 8, starts right away at 10, and once the queue timer hits **1 minute** it launches with whoever is queued.
- **Raids**: three maps.
  - **Dockyard**: container yard, cranes, warehouses, Harbor Office vault.
  - **Pinewood Outpost**: forest, military outpost, bunker vault.
  - **Old Town**: streets, apartments, bank vault.

  Each raid lasts 25 minutes. Reach an extraction zone (green smoke) and stand in it for 8 seconds. If you die, you lose what you brought and your body drops it for others to loot.
- **Raiders**: squad NPCs that patrol, hear gunshots and footsteps, notice you over time, take cover, peek, fire bursts with human-like aim, flinch when hit, ragdoll on death and drop their gun and loot.
- **Guns**: 50 original guns (pistols, revolvers, SMGs, shotguns, rifles, DMRs, snipers, LMGs) in 5 rarity tiers.
  - Common ones turn up everywhere and Rare/Epic ones are hard to find.
  - 7 **Vault** guns spawn only inside vaults. Open a vault with a Vault Keycard, or grab the hack panel and hold on for 30 seconds while the alarm draws every Raider nearby.
- **Holo sights** (6 types) are found in optics boxes. Bring a sight to a gun's top rail and let go to mount it. The reticle is projected at infinity, like a real holo sight.
- **Effects**: muzzle flash with light, muzzle smoke, ejected brass, tracers, sparks, dust and debris, and bullet holes. Blood comes as spray, mist, wound decals, splatter on walls and floors, drips while bleeding, and pools under bodies.
- **Sound**: every sound is synthesized in code. This includes layered gunshots with echo tails, suppressed shots, reload mechanics, footsteps per surface, impacts, bullet cracks, alarms and ambience.

### VR controls
| | |
|---|---|
| Left stick | Move. Click to sprint (uses stamina) |
| Right stick | Snap or smooth turn. Click to crouch toggle (real crouching also works) |
| Grip | Grab, two-hand a gun (grab the handguard), pull a slide or charging handle |
| Trigger | Fire. Point at buttons and pull the trigger to click |
| A / X | Drop magazine |
| B / Y | Rack / release slide. Switches fire mode when a round is chambered |
| Chest | Grab a fresh magazine for the gun in your other hand (from your ammo reserve) |
| Right hip | Pistol holster |
| Right shoulder / lower back | Long guns |
| Left shoulder | Backpack: pull it off to open the 3x3 pockets |
| Med near chest + trigger | Heal (bandage stops bleeding, medkit heals over time, stim gives instant HP + stamina) |

### Desktop controls (no headset)
WASD move · mouse look · Shift sprint · C crouch · E grab what you look at / drop · LMB fire / click · RMB aim · R reload · F rack / open / interact (hold F on a vault hack panel) · X drop mag · 1/2/3 primary / secondary / pistol · Tab backpack · G drop (into the open backpack)

## Code layout
```
Assets/RagoExtract/
  Runtime/   core game (no package dependencies; always compiles)
    Art/     procedural mesh kit, materials/textures, gun, character and sight builders
    Audio/   sound synthesis + pooled 3D playback
    Fx/      muzzle flash, tracers, brass, impacts, decals, blood
    Items/   item database (50 guns, sights, meds, loot), guns, mags, containers
    Player/  XR input, physics hands, locomotion, ragdoll body, gear, vitals
    AI/      raid NPCs + squad director
    World/   level builder, raid maps, bunker, market, crates, vaults, extraction
    Hub/     kiosk / matchmaking UI, traders, stash, settings
    Net/     transport-agnostic replication (players, shots, hits, loot, NPCs)
  Net/       Netcode + Lobby + Relay backend (compiles only when those packages exist)
  Voice/     Vivox proximity voice (compiles only when Vivox exists)
  Editor/    first-open automation + the Rago Extract tab + APK builder
  Shaders/   lit (triplanar), unlit FX, holo reticle, sky
```
If an optional module ever fails to compile against a future package version, the editor switches it off so the game keeps running offline. Use **Retry** in the tab to switch it back on.
