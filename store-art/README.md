# Store art for the DLC add-ons

One folder per add-on, named by its SKU (what you type into the Meta dashboard). Each has:

| File | Meta dashboard box |
|---|---|
| `logo_transparent_1800x600.png` | Logo (transparent background) |
| `cover_landscape_2560x1440.png` | Cover art > Landscape |
| `cover_square_1440x1440.png` | Cover art > Square |
| `cover_portrait_1008x1440.png` | Cover art > Portrait |
| `cover_mini_landscape_1360x765.png` | Cover art > Mini landscape |
| `banner_1080x360.png` | the 1080 x 360 image |
| `screenshot_*_2560x1440.png` | Screenshots (one per skin, plus one for the items if the pack has any) |
| `trailer_1920x1080.mp4` | Trailer > Video (H.264 + AAC, MP4). Use the landscape cover as the trailer's cover image |

Made from the game's own skin patterns (`GunSkins.cs`). Music: Jingle Bells (public domain) for the Holiday Pack, original synth tracks for the rest.
